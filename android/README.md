# Android TWA project

This folder is reserved for the Bubblewrap project generated in GitHub Codespaces. Run `bubblewrap init --manifest=https://edupulse.cc.cd/manifest.json` from this repository root and choose `android` as the output directory if prompted, or generate in a temporary directory and move the generated project here. The GitHub Actions workflow expects `android/twa-manifest.json` and the generated project files in this folder. Never commit signing keystores or passwords.
